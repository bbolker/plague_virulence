The form we should use is

$$S' = \rho(K-S)\left(\frac{S}{K}\right)^\theta.$$

Thus, when $\theta=0$,

$$S' = \rho(K-S),$$

and when $\theta=1$,

$$S' = \rho S(K-S)/K,$$

so $\rho$ matches both $\varepsilon$ and $r$

There is an infelicity here, which I think we should ignore for now.

In the linear case $\theta=0$, we have explicit deaths, whereas for $\theta=1$, we explicitly have \emph{no} deaths. In between, we're kind of phenomenological (it is not clear how best to parse the S' given above into births and deaths. This seems fine for our purposes but is worth noting.
